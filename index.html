GETTING STARTED

Make this room yours.

Choose a display name, a room name and a shared passphrase. Both people need the same room and passphrase to read messages.

Prototype encryption; not audited or a replacement for Signal. Anyone with your passphrase can read room messages.

SECURITY NOTES

What this prototype protects

A room passphrase derives an AES-256-GCM key in your browser. The server stores only ciphertext and an opaque IV, and keeps messages in memory.

This isn't the Signal Protocol: there are no identity keys, forward secrecy, device verification, or audited key exchange. Anyone with the passphrase can read the room. Use only for a local demo, never sensitive conversations.
